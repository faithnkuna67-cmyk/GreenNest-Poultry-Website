# GreenNest Poultry Supplies Website

## Project
WEDE5020 POE – Part 2: CSS Styling and Responsive Design

## Project Overview
GreenNest Poultry Supplies is a hypothetical small business website developed as part of an academic web development project. The website provides information about the business, displays poultry products and allows visitors to make enquiries.

Part 2 focuses on improving the website's appearance, layout, typography and responsiveness using CSS.

## Technologies Used
- HTML5
- CSS3
- JavaScript
- GitHub

## Website Pages
- `Index.html` – Home page
- `About.html` – About the business
- `Products.html` – Poultry products
- `enquiry.html` – Customer enquiries
- `Contacts.html` – Contact page

# CSS Styling for Desktop Solution

## 2.1. Create an External Stylesheet
An external CSS file named `style.css` is stored inside the `css` folder. The stylesheet is used to control the appearance and presentation of the website.

## 2.2. Establish a Base Style
A CSS reset and base styles were added to provide consistent spacing, sizing, colours and page formatting.

## 2.3. Apply Typography Styles
Typography styling was introduced to improve readability and create a consistent appearance for headings, paragraphs, navigation links and other text.

## 2.4. Create a Layout Structure
CSS Grid and Flexbox are used to organise website content. Product cards are arranged in columns on wider screens.

## 2.5. Apply Visual Styles
Colours, backgrounds, borders, spacing, buttons and hover effects were added to improve the website's visual appearance and usability.

# Responsive Design

## 3.1. Breakpoints
Media queries were added to adjust the website layout for different screen sizes. The design includes desktop, tablet and mobile layouts.

## 3.2. Relative Units
Relative CSS units such as percentages, `rem` and flexible sizing are used where appropriate to support adaptable layouts.

## 3.3. Responsive Images
Responsive image techniques, including the `picture` element, `srcset` and `sizes`, will be documented here once implemented and tested.

## 3.4. Test and Iterate
The website will be tested at desktop, tablet and mobile screen sizes using browser developer tools. Screenshots will be added as evidence of responsive testing.
