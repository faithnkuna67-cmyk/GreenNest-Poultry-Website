# GreenNest Poultry Supplies Website

## Project
WEDS020POE – Part 1 Website Development Project

## Overview
GreenNest Poultry Supplies is a hypothetical small business website created for an academic web development project. The website presents poultry products, organisation information, an enquiry form and contact details.

## Technologies
- HTML5
- CSS3
- JavaScript
- GitHub

## Pages
- `index.html` – Home
- `about.html` – About
- `products.html` – Products
- `enquiry.html` – Enquiries
- `contact.html` – Contact
